## 부하테스트 실측과의 대조 (참고, 채점 아님)

T2-A 실측의 판정은 "CPU 포화 + 커넥션 풀 병목 복합"이었다. 에이전트는 풀 고갈 축은
메트릭·로그·트레이스로 확정했으나, **BCrypt CPU 포화 축은 지목하지 못했다** —
process/system CPU·톰캣 스레드 지표가 수집 대상에 없어 계측 공백으로만 기록했고,
본인도 "auth 파드 CPU/스로틀링" 계측을 재발 방지 항목으로 요구했다.
후보 3(점유 시간 증가 약 1.6초/건)이 실제로는 BCrypt로 인한 CPU 대기를 간접적으로 본 것에 해당한다.
