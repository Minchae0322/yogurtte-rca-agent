# 14. 콘텐츠 현실모드 - VU를 "동접자"로 되돌린 시험

> **결론:** 부하모델의 피크 동접 **1,250명을 think time 분포로 모사**해 걸었더니
> **p95 68.7ms · 실패 0 · 8분 30초 완주**. T2-B 압력 모드(300 VU에서 p95 2.16s)와
> 같은 시스템인데 결과가 30배 차이 나는데, 이것이 **"VU는 사용자가 아니다"의 실측**이다.
> 모델이 말하는 평시 피크(83 rps)를 현재 구성은 여유롭게 처리한다.

| 구분 | 내용 |
|---|---|
| 상태 | 실측 완료 · 2026-08-30 (v1 16:32 · v2 16:44) |
| 목적 | 부하모델 **baseline 티어**(평시 피크 83 rps) 검증 - 한계 탐색이 아니다 |
| 스크립트 | [b-content-realistic.js](../../b-content-realistic.js) · `ramping-vus` **폐루프 + think time** |
| 부하 | **VU 1,250 = 동접 1,250명** (2m 램프 → 5m 유지 → 1m 하강) · 직결 경로 |
| 판정 | **통과** - SLO(p99<800ms) 충족, 실패 0 |

## 이 시험이 다른 회차와 다른 점 - 축이 다르다

같은 content 읽기 경로인데 T2-B(`b-content-spike.js`)와 **VU의 의미가 정반대**다.

| | T2-B 압력 모드 | **현실 모드 (이 폴더)** |
|---|---|---|
| VU의 정체 | 쉬지 않는 요청 발사기 | **사용자 1명** (행동 후 쉼) |
| think time | 없음 | **가중 분포** - 헤비 20% 1~3s · 일반 70% 5~25s · 느긋 10% 30~50s (가중 평균 ~15s) |
| VU당 rps | ~12 | **~0.067** (1/15초) |
| 300 VU의 의미 | ~394 rps (극한) | 동접 300명 (~20 rps) |
| 쓰는 곳 | 한계·병목 탐색 | **동접 수용 검증** |

**회차 비교 시 두 축을 섞지 않는다.** 같은 VU 숫자가 180배 다른 부하를 뜻하므로,
"몇 VU를 통과했다"를 축 표기 없이 인용하면 규모가 왜곡된다.

## 실측

| 회차 | 시각 | 요청 | p90 / **p95** / max | 실패 | 완주 |
|---|---|---:|---|---:|---|
| v1 (think 분포 1안) | 16:32~16:40 | 30,351 | 62.7 / **68.7ms** / 275ms | **0** | 완주 |
| **v2 (분포 재배분)** | 16:44~16:52 | 33,400 | 62.4 / **68.8ms** / 516ms | **0** | 완주 |

두 회차의 차이는 think time 분포의 비중뿐이다 - v1(헤비 10 / 일반 65 / 느긋 25)이 실사용
템포보다 느긋하다고 판단해 v2(헤비 20 / 일반 70 / 느긋 10)로 재배분했다. **가중 평균 15초는
보존**했는데, 이 값을 바꾸면 부하모델 §1의 사슬(83 rps · 동접 6,000 환산)이 전부 재계산되기
때문이다. 결과: 요청 수는 +10%(30,351 → 33,400), 지연은 사실상 동일 - **분포의 모양보다
평균이 지배한다**는 것이 부수 확인이다.

## 판정

1. **모델의 평시 피크는 여유롭게 통과한다.** 동접 1,250명 = 목표 83 rps에서 p95 68.8ms로,
   SLO(p99<800ms) 대비 10배 이상 여유. 개선 캠페인의 성과가 평시 구간에서는 충분함을 확인.
2. **폐루프라는 한계는 그대로다.** think time을 넣어 현실적이지만 executor는 `ramping-vus`라
   서버가 느려지면 부하도 함께 줄어든다. 진짜 수용 한계는 열린 루프
   ([13-순간폭주](../13-순간폭주/README.md)의 arrival-rate)가 재고, 그 회차에서는 같은
   시스템이 급증에 실패 64.8%로 무너졌다 - **폐루프의 여유를 수용력으로 읽으면 안 된다.**
3. 미측정: 이 회차의 서버측 소급(Mimir)은 obs 노드 다운으로 불가, ktop만 확보.
