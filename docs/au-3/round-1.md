./chaos.sh: line 463: label: unbound variable                   ← 🔴 여기서 셸 종료

`inject_AU_3()`의 순서는 ① 평시 트래픽 → ② 시크릿 백업 → ③ `patch` → ④ `rollout restart`이고,
크래시 지점(`au3_fire()` 첫 줄)은 **①의 내부**다. 시크릿은 손대지 않았다.

**타임스탬프가 이를 뒷받침한다** — `평시 트래픽 60초` 로그와 크래시가 **같은 초**에 찍혔다.
warm이 실제로 돌았다면 patch는 60초 뒤였다.

> **부수 확인**: 이 게이트가 만든 500 트레이스가 **AU-2 회차 2 실행 2의 조사 창에 섞여 들어가
> 1순위 오답을 만들었다**(*"JWT 서명 키 변경"*). 문항 간 오염 사례로 별도 추적한다.

## 3.1 결함 21ⓐ — `chaos.sh:463`

```bash
local secs="$1" label="$2" out="…-$label-$RUN_TS.txt" i tid code
#                  ↑ 아직 미대입       ↑ 여기서 확장 → set -u(21행) → 셸 종료
```

bash는 `local`의 **인자를 전부 확장한 뒤** 대입한다. AU-3가 첫 실행이라 이제 드러난 잠복 버그다.

```
$ bash -c 'set -u; f(){ local a="$1" b="x-$a"; }; f A'        → bash: a: unbound variable
$ bash -c 'set -u; f(){ local a="$1"; local b="x-$a"; }; f A' → 정상
```

## 3.2 결함 21ⓑ — 주입값이 유효한 Base64가 아니다 · **고쳐도 증상이 안 남**

주입값 `chaos-au3-drift-value-not-a-real-secret-0000000000`에 `-`가 있다(기본 Base64 알파벳 밖,
디코드 실패 실측). 세 서비스 모두 생성자가 `Base64.getDecoder().decode()` → `Keys.hmacShaKeyFor()`다.

```
빈 생성 실패 → content 파드 기동 불가 → rollout 정지 → 구 파드가 계속 200 서빙
= 시크릿 드리프트가 아니라 배포 실패. 증상 0건
```

**ⓐ만 고치고 돌렸다면 "주입했는데 아무 일도 안 일어남"으로 한 회차를 더 잃었다.**

## 3.3 결함 21ⓒ — `jwtfail(1h): 0건`은 오보고였다

게이트가 서명 훼손 토큰을 던진 **직후**(571행 → 572행, 대기 없음) Loki를 조회했다. 수집
에이전트 배치 + Loki 쓰기 지연 때문에 아직 안 들어온 것이다.

**정규식 문제가 아니다** — 셀렉터에 이미 `Signature`가 있었고, 채점자가 나중에 같은 창을
조회하니 스택 전문이 나왔다. **`answer.md` 체크리스트가 이 0건을 근거로 "앵커 ⓑ를 요건에서
빼라"고 지시하고 있어, 하마터면 멀쩡한 요건을 폐기할 뻔했다.**

## 3.4 결함 20 — 세 서비스가 문자 그대로 같은 코드였다

`toy-content` `JwtParser` · `toy-chat` `JwtParser` · `toy-auth-user-region` `JwtProvider`,
전부 jjwt 0.11.5.

```java
import io.jsonwebtoken.*;                 // io.jsonwebtoken.security 는 안 들어온다
catch (SecurityException | MalformedJwtException e) { }   // ← java.lang.SecurityException 으로 해석
```

Loki 스택이 실제 타입을 확정해 준다 — **`io.jsonwebtoken.security.SignatureException`**.
`java.lang.SecurityException`의 하위가 아니라 **미포착 → 필터 밖 전파 → 500**.

**부수 결함: catch 블록이 전부 비어 있었다**(주석만). 401이 나가도 사유가 어디에도 안 남아
**앵커 ⓑ가 원리적으로 검증 불가**였다 — 그것이 *"주입 전 검증 필수"* 로 남아 있던 진짜 이유다.

# 4. 앵커 전제 반증 — 채널 감사 실측

게이트가 만든 500 트레이스 `6a69e01bc0116147bba4b75907e9d57e`(11:12:27Z)를 채점자가 직접 조회했다.

**Tempo** — `{ status = error }` 한 번에 **Top-1 적중**:

```
• http get /feeds/following        status=STATUS_CODE_ERROR
    error     = JWT signature does not match locally computed signature.
    exception = SignatureException          status = 500
• security filterchain after       ERROR
• secured request                  ERROR
• security filterchain before      UNSET    ← 중단 지점이 그대로 보인다
```

**Loki** — 채널별로 갈린다:

| 쿼리 | 결과 |
|---|---|
| traceId 전량 (`traceIdQuery`) | ❌ `GET /api/feeds/following 200 - 4ms` **INFO 한 줄뿐** |
| `\|~ "ERROR\|WARN"` (`errorWarnQuery`) | ⚠️ `dispatcherServlet … threw exception` **헤더 줄만** — JWT 언급 없음 |
| `\|~ "Signature\|Jwt"` | ✅ 스택 전문 + `JwtParser.validateToken(JwtParser.java:31)` |

**같은 요청 하나가 채널마다 다른 이야기를 한다** — Tempo는 원인을 말하고, traceId 로그는
*"200 성공"* 이라 말하고, 에러 로그는 JWT를 언급조차 안 한다.

## 앵커에 미치는 영향

| 앵커 요건 | 전제 | 실측 | |
|---|---|---|---|
| 3) 탐색 15 | *"401은 `status=error`가 아니다"* → 8점 구간이 *"에러 검색만 돌려 **0건**으로 종결"* | **에러 검색 1회에 Top-1** | 🔴 **난도 설계 붕괴** |
| 2)ⓐ 앱 버그 배제 | 부재 신호로 도달 | 중단 지점이 span으로 직접 보임 | ✅ 더 쉬움 |
| 2)ⓑ 만료 배제 | **Loki** 실패 사유 | **Tempo**에 `exception=SignatureException` | ⚠️ 성립하되 **채널이 다름** |
| 1) 원인 40 · 5) 오귀인 | 핵심 함정 = "토큰 만료 오판" | 트레이스가 *"signature does not match"* 를 축자로 자백 | 🔴 **함정 소멸** (AP-3 구조) |
| 4) 영향 10 · 2)ⓒ | 전역 401 급증 | 500이고, 주입 자체가 미실행 | — 미실측 |

**STATUS.md의 AU-3 실행 금지 근거가 정반대였다.** *"도달 채널 0의 최난도"* 가 아니라
**Tempo가 원인을 자백하는 최이도 문항**이었다.

## 결함 20 수정이 이 전제를 되돌린다

| | 수정 전 (실측) | **수정 후 (예측)** |
|---|---|---|
| 응답 | 500 | **401** ← 앵커 v2 원 전제 복귀 |
| Tempo | `status=error` + 축자 자백 | **에러 신호 소멸** → 부재 신호만 |
| Loki | 스택 있으나 `traceId=NONE` · 라인 필터 밖 | **`WARN` + traceId 정상** → 양쪽 쿼리 도달 |
| 만료 vs 서명 | 구별 불가(둘 다 무로그) | **다른 문구** → ⓑ 성립 |

**즉 앵커를 고칠 필요가 없어진다.** 앵커를 실측에 맞추는 대신 앱을 앵커에 맞췄고,
AU-3는 원래 설계였던 **로그 전용 최난도 문항**으로 돌아간다.

> ⚠️ **이건 예측이고 아직 반증 가능하다.** AP-1·AP-2에서 인과 예측이 연속 반증된 전례가 있다.
> **배포 후 서명 훼손 토큰 1회로 즉시 검증된다 — 주입 불필요.**
> **미확인 전제: JwtFilter 시점에 MDC traceId가 실려 있는가.**
