> ## 🔴 실행 2로 **§8.1의 첫 완전 충족**이 나왔다 — 편차 0
>
> 회차 2가 스스로 지정한 실험이다: *"**같은 자연어 입력**으로 한 번 더 →
> **90 근처 = 구성 효과** · 75 근처 = 분량/실행 편차"*. **90이 나왔고 항목별로도
> 30·30·20·10으로 전부 같다.**
>
> **통제 변수 다섯이 고정됐다** — 질문 문안(문자 그대로) · 자(4항목 anchors.md v2) ·
> 입력 모델 · 도구(`src/`·`prompts/` 변경 0건) · 주입 스펙.
> **주입은 별개**다(18시간 간격, 다른 데이터) — CH-3 쌍이 4분 간격 같은 데이터라
> 실행 분산을 못 잰 것과 다르다. **실행 간 분산을 실제로 잰 첫 쌍이고, 그 값이 0이다.**
>
> **⚠️ 회차 1(75) → 회차 2(90)의 +15는 여전히 미분리다.** 이번 N=2가 지운 것은
> **"실행 운"** 하나뿐이고, 입력 모델·Loki 수정·앵커 개정 셋은 그대로 남아 있다.

> **회차 2는 회차 1의 N=2 표본이 아니다.** 입력 모델(traceId → 자연어+탐색)·Loki 수집
> (0건 → 9줄)·출력 분량(2.6배)·앵커(v1 → v2)가 동시에 바뀌었다. **다른 구성의 첫 표본**으로
> 두고, §8.1 평균에 넣지 않는다 — 근거는 [round-2.md](round-2.md).
