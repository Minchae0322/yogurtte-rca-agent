## 🔴 무효가 된 첫 실행 — CLI 자동 갱신이 측정을 깨뜨린다

첫 실행(04:52Z)에서 프로브가 죽었다.

```
13:56:23 WARN ClaudeCliLlmClient - 오버헤드 프로브 실패:
  CreateProcess error=216, %1의 버전이 실행 중인 Windows 버전과 호환되지 않습니다
```

**본 분석 호출은 13:53에 성공했는데 13:56 프로브만 실패했다.** 원인은 실측으로 확정된다 —
`claude.exe`의 파일 수정 시각이 **13:56**(프로브 실패와 동일), 버전이 **2.1.221 → 2.1.222**다.
**CLI가 조사 도중 자기 자신을 교체했다.**

**설령 프로브가 성공했어도 그 값은 무효였다.** §2.2대로 오버헤드는 CLI 버전에 붙는 값인데,
그 실행은 **분석 호출이 2.1.221에서 나고 프로브는 2.1.222를 쟀을 것**이다. 서로 다른 버전을
재는 프로브는 정의상 쓸 수 없다.

### 이것이 이 회차의 가장 중요한 산출물이다

**한 번의 사고가 아니라 구조적 노출이다.** CLI는 배경에서 스스로 갱신되고 조사 1회는 3분을
넘긴다. 그 사이 갱신이 걸리면 두 갈래다.

| | 무슨 일이 나나 | 알아챌 수 있나 |
|---|---|---|
| ⓐ 프로브가 죽는다 | 토큰 축을 잃는다 | **된다** — 로그와 리포트에 남는다 (이번 경우) |
| ⓑ **프로브가 살아서 다른 버전 값을 돌려준다** | **틀린 오버헤드로 컨텍스트 토큰을 계산한다** | **안 된다 — 로그도 안 남는다** |

**ⓑ가 진짜 위험이고, 이번에 ⓐ가 난 것은 운이 좋았던 것이다.**
대응안은 [넘기는 것 ①](#다음-회차로-넘기는-것)에 적었다.
