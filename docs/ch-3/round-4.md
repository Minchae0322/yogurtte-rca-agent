# C-5가 만든 부수 효과 — 조치 절의 구조가 바뀌었다

C-5는 6) 조치를 겨냥했는데, 실제로는 **4) 영향 판정을 열었다.**

```text
### 이미 발생한 피해 — 복구 가능한가
복구 조치 불필요(이미 자체 복구됨).                       ← 4) 영향 10점의 근거
- 알림 3건 모두 최종 처리 완료 + FCM success=1, lag 0
- 남은 피해는 되돌릴 수 없는 종류다: 푸시 알림이 최대 8분 38초 늦게 도착
- 사용자 체감 경로에 대한 데이터는 부족하다               ← 공백을 스스로 표기

### 재발 방지        (5건)
### 복구 확인        (2건)
### 추가 수집이 필요한 것 (데이터 부족)   (5건)            ← 지시하지 않은 절
```

**"이미 발생한 피해는 복구 가능한가"를 묻자 영향 판정이 확정으로 나왔다.**
회차 3에서 4)가 5점이었던 이유가 *"판정 유보"* 였으므로, 이 항목은 C-5의 간접 효과다.
