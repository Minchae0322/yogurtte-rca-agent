## 🔴 에이전트는 불일치를 **감지했지만 행동할 수단이 없었다**

이번 회차가 회차 1·2에 없던 것을 보여준다 — 리포트가 **질문과 증거의 어긋남을 스스로 지적**했다.

> *"사용자 요청 경로는 정상이었음: `http post /battles/{battleId}/items/{itemId}/comments` 스팬
> status=200 … MySQL 쿼리 4건 모두 수 ms, Redis GET 0.55ms.

그리고 3순위로 *"헬스체크 30초 블로킹이 체감 버벅임의 유력 후보 메커니즘이나 **직접 계측값 없음**"*
을 세웠다. **즉 에이전트는 "내가 받은 증거로는 이 질문이 안 풀린다"를 정확히 알았다.**
그런데 **다른 구간을 다시 찾을 경로가 없다** — 창은 이미 확정됐고 수집은 끝났다.

**이것이 [B-23(탐색 후 검증 패스)](../round-3/README.md)의 근거다.** 에이전트가 사후에 수동으로

비용도 싸다(컨텍스트 수백 자).

> ⚠️ **§8.1 평균은 회차 1·2 쌍으로 이미 성립해 있다**(4 ± 0). 2b를 같은 평균에 합치지 않는다 —
> 회차 1·2는 **같은 주입**이고 2b는 **다른 주입**이라 성격이 다르다.
