# 변경 ID 색인

**개선 항목이 `B-1`~`B-43`까지 늘었는데 정의가 `round-2/`~`round-6/` 다섯 폴더에 흩어져 있어
번호만 보고는 무엇인지 알 수 없었다.** 이 문서는 **ID → 한 줄 → 상태 → 원문 위치**만 담는다.
설명 본문은 각 회차 폴더에 있고 여기에 복제하지 않는다(같은 표가 두 곳에 살면 갈라진다).

## 변경군

| 접두 | 무엇 | 왜 나누나 |
|---|---|---|
| **A** | 앱 계측 (toy-content·toy-chat·toy-user) | 배포가 필요하고 **문항 자체를 바꾼다** |
| **B** | 조사 도구 (rca-agent 코드·설정) | 주입 없이 재조사로 검증된다 |
| **C** | 프롬프트 (`prompts/*.md`) | 재시작 없이 바뀐다 |

**한 회차에 두 군을 섞지 않는다** — 점수가 움직여도 무엇 때문인지 증명할 수 없다.

## 상태 범례

| | |
|---|---|
| **적용** | 코드에 들어가 있고 회차가 돌았다 |
| **대기** | 대기열에 있고 미구현 |
| **보류** | 선행 조건이 있어 일부러 미룸 |
| **폐기** | 반증됐거나 효과 없음이 확인됨 |
| **확인필요** | 🔴 ID는 쓰이는데 **정의가 문서에 없다** |

## 유지 규칙

- **새 ID를 만들면 이 표에 한 줄을 같이 넣는다.** 안 넣으면 다음에 또 못 찾는다.
- **설명은 회차 폴더에, 색인은 여기에.** 본문을 복제하지 않는다.
- 상태가 바뀌면(대기 → 적용 / 폐기) **여기부터 고친다.**
