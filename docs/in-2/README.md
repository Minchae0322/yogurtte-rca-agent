## 스크린샷 공통 팁

- Grafana 시간대는 KST(UTC+9). 주입 창 = **KST 07-28 00:45:58 ~ 00:53:19**. 트리거 = **00:51:53 KST**.
- 이 문항의 그림 세 장: ① Tempo 장애 트레이스(`6a677e99…` 60,020ms error span + chat 부재), ② Loki `알림 발행 실패` ERROR + producer WARN 스팸, ③ `kafka_brokers` 그래프의 **선이 끊기는 구간**(0이 아니라 부재 — 그 공백 자체가 스샷 포인트).
- **유실 vs 지연 갈래 주의**: 다운이 5분(메타데이터 만료)을 못 넘으면 producer가 버퍼에 쥐고 있다 복구 후 발행 성공(지연 도착). 유실은 트리거 후 60초+ 다운 유지 + 5분+ 경과라야 난다.
